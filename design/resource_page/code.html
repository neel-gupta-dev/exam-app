Introduction to Wave Function Collapse

notes Active Study Notes

12:45

Key takeaway about wave functions: The probability density is given by the square of the magnitude of the wave function |ψ|². This transition from probability to certainty happens upon measurement.

24:12

Compare this with Schrödinger's cat paradox. The superposition of states exists as long as the box is not opened (no external measurement).

  • Superposition: state A + state B
  • Measurement: forces a collapse to state A XOR state B
